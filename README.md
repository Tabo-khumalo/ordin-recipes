## The HTML Boilerplate

The HTML boilerplate is the basic structure that every HTML document starts with. It includes elements such as `<!DOCTYPE html>`, `<html>`, `<head>` and `<body>`, which help the browser understand how to display the webpage.

## Basic HTML Tags

HTML tags are used to structure and organise content on a webpage. Tags such as headings (`<h1>`), paragraphs (`<p>`), links (`<a>`) and lists (`<ul>`, `<li>`) tell the browser what type of content to display.

## Absolute and Relative Links

Absolute links contain the full URL of a webpage, including the protocol and domain name, such as `https://www.google.com`. Relative links point to another file or page within the same website or project without using the full URL, making them useful for linking between pages in your own website.

## Embedding Images

Embedding images in HTML allows you to display pictures on a webpage using the `<img>` tag. The `src` attribute specifies the image location, while the `alt` attribute provides a text description of the image for accessibility and when the image cannot load.
